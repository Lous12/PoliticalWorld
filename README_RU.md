> **Играй с политикой — или возьми API и сделай что-то совсем своё.**

Political World начинался как обычный мод про политику: идеологии, партии, выборы, формы правления, кризисы, международные блоки и всё, что происходит между государствами.

Но по ходу разработки у мода появился собственный публичный API. И довольно быстро стало понятно, что ограничивать его одной политикой было бы странно. Если API уже умеет хранить данные аддонов, передавать события, проверять условия и запускать действия, то на нём можно строить намного больше.

Поэтому теперь у проекта две стороны: **сам Political World остаётся политическим модом**, а `PoliticalWorldAPI` постепенно превращается в **общую платформу для аддонов**.

## Для игроков

Political World добавляет в WorldBox политический слой, но не пытается просчитывать каждого жителя каждую секунду.

Сейчас в моде есть:

- идеологии и их течения;
- политические партии, лидеры, поддержка и радикализм;
- разные формы правления и политические системы;
- выборы, советы, партийные съезды и смена руководства;
- стабильность, политические кризисы, мятежи, перевороты и революции;
- международные блоки и работа с ванильными Alliance;
- настоящие саммиты, на которые правители физически приезжают в столицу;
- подготовка к войне, дипломатические кризисы и военная усталость;
- Political Map с режимами партий, идеологий и напряжения.

Главная идея простая: политика должна ощущаться глубокой, но при этом не превращать игру в тяжёлый симулятор таблиц.

## Для разработчиков

Публичная точка входа:

```csharp
using Lous12.PoliticalWorld;

if (!PoliticalWorldAPI.IsCompatible(1, 9))
    return;
```

В API 1.9 уже есть:

- регистрация аддонов и проверка их данных;
- необязательная локализация с запасным английским текстом;
- идеологии и пользовательские формы правления;
- работа с партиями, государствами и правителями;
- Actions и Rare Events;
- Event Bus;
- готовые Conditions и Effects;
- приватные данные аддона: `int`, `string`, `bool`, `float`;
- данные и теги для государств и партий;
- диагностика и понятные результаты операций;
- пакетная регистрация контента и поиск того, что добавил конкретный аддон.

**Перевод не обязателен.** Если автор сделал аддон только на английском, русская версия игры не должна ломать его или показывать `missing text`. В таком случае API просто покажет английский текст.

И это только начало. Политические функции останутся важной частью API, но они не должны быть его пределом.

```text
WorldBox + NeoModLoader
        ↓
Political World
  ├─ политический мод
  └─ публичный API
        ↓
PoliticalWorldAPI 1.9
        ↓
Твой аддон
  ├─ политика
  ├─ фэнтези
  ├─ религии
  ├─ экономика
  ├─ события
  ├─ инструменты
  └─ всё, что ты придумаешь
```

Наше главное правило:

> **Если аддону приходится лезть во внутренности Political World, значит, скорее всего, в публичном API не хватает нужной возможности.**

## Зачем вообще делать API универсальным?

Потому что мы не хотим решать за других авторов, что им можно создавать.

Кому-то достаточно одной новой идеологии. Кто-то захочет сделать фэнтезийную политику. А кто-то вообще не будет трогать политику и попробует построить через API систему религий, магии, торговли, болезней, династий или собственный редактор сценариев.

Не всё это уже поддерживается готовыми методами. Это направление, в котором мы развиваем API: дать автору **универсальные инструменты**, а не заставлять его ждать, пока нужная механика появится в основном моде.

Подробнее: **[Видение фреймворка](docs/ru/FRAMEWORK_VISION.md)**.

## Совместимость

| Компонент | Версия |
|---|---|
| Political World | 1.7.0 Public Beta |
| Public API | 1.9.0 |
| WorldBox PC | 0.51.2 / build 719 |
| NeoModLoader | 1.2.0.1 |

Версия API живёт отдельно от версии самого мода и версии WorldBox. Это позволяет развивать инструменты для разработчиков, не привязывая каждое изменение API к большому игровому обновлению.

> **Играй с политикой. Или возьми API и сделай что-то своё.**

Political World — это одновременно мод про политику для WorldBox и развивающаяся платформа для аддонов через `PoliticalWorldAPI`.

## Сейчас

- **Political World:** 1.7 Public Beta
- **Public API:** 1.9.0
- **Главное направление разработки:** API 1.10 — General Framework
- **Поддерживаемая связка:** WorldBox PC 0.51.2 / build 719 + NeoModLoader 1.2.0.1

Какое-то время крупных игровых обновлений может быть меньше, потому что основной упор идёт на API. Сам мод не заброшен.

## Для игроков

Political World добавляет идеологии, партии, формы правления, выборы, кризисы, международные блоки, физические саммиты, подготовку к войне и режимы Political Map.

## Для разработчиков

Public API уже умеет регистрировать аддоны, подставлять запасную локализацию, хранить данные и теги, передавать события, запускать Actions и Rare Events, использовать Conditions и Effects и работать с политическими реестрами.

Следующий шаг — сделать больше этих инструментов полезными и за пределами политики.

## Сообщество

Через GitHub Discussions можно задавать вопросы, показывать WIP, просить новые возможности для API и отправлять аддоны на проверку совместимости.

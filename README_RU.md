Political World — это одновременно:
- мод про политику для WorldBox;
- и развивающаяся платформа для аддонов через `PoliticalWorldAPI`.

## Для игроков
Мод добавляет идеологии, партии, формы правления, выборы, кризисы, блоки, саммиты, подготовку к войне и режимы Political Map.

## Для разработчиков
Public API уже умеет работать с регистрацией аддонов, fallback-локализацией, данными и тегами, Event Bus, Actions, Rare Events, Conditions, Effects и диагностикой.

# Made with Political World

This is the community addon catalog for projects built on Political World.

The public website catalog lives here:

- [English community catalog](docs/en/community-addons.md)
- [Русский каталог аддонов](docs/ru/community-addons.md)

## Catalog policy

An addon is added to the verified list after the Political World maintainer checks it on a supported setup and confirms that it launches and its advertised core function works.

Verification is a compatibility check, not a permanent guarantee, security certification, or promise that an addon contains no bugs.

Small projects are explicitly welcome. A one-ideology addon, one-event addon or learning experiment can be listed alongside large overhauls.

## Submit an addon

Open an Issue or Pull Request with:

- addon name;
- author;
- short description;
- source/download link;
- Political World version;
- minimum PoliticalWorldAPI version;
- other dependencies;
- whether it uses only the public API;
- a short test checklist.

Public-API-only addons are preferred because they are more likely to survive internal Political World refactors.

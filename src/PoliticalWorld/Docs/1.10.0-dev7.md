# Political World 1.10.0-dev7

## Separatism simulation
- Separatist Sentiment is no longer UI-only.
- Non-capital settlements can progress through: **Separatist Movement → Autonomy Campaign → Secession Crisis**.
- Escalation uses derived separatism plus Government Loyalty and applies controlled stability pressure.
- Active separatist stages lower the local stability target.
- Autonomy/secession stages raise the threshold and chance for Political World rebellions, allowing a politically alienated settlement to break away before reaching absolute 0-15 local stability.
- Neighbouring autonomy/secession cities can join a rebel state more naturally.
- Hysteresis prevents threshold spam when a settlement hovers near a boundary.
- Ownership changes clear the previous ruler's local separatist stage.

## PoliticalWorldAPI 1.18
- `PoliticalWorldAPI.Settlements.GetSeparatistStage(City)`
- `PoliticalWorldAPI.Settlements.HasSeparatistMovement(City)`
- New typed events:
  - `settlement.separatism.movement-started`
  - `settlement.separatism.autonomy-demanded`
  - `settlement.separatism.secession-crisis-started`
  - `settlement.separatism.ended`
- Core event payloads can now include the concrete `City`.

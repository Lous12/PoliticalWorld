# Political World 1.10.0-dev6

## Settlement politics
- Added **Government Loyalty** to the Central Government block.
- Added **Separatist Sentiment** as a separate 0-100 derived metric.
- Loyalty reacts to local stability, state-ideology support, national stability, political division, hostility, ideological alignment and capital status.
- Separatism rises from instability, weak support for the state ideology, division, hostility, national crisis and local/state ideological mismatch. Capitals and one-city kingdoms report 0 separatism.
- Neither value is a fake persisted stat: both are derived from the political simulation on demand.

## PoliticalWorldAPI 1.17
- Added `PoliticalWorldAPI.Settlements.GetGovernmentLoyalty(City)`.
- Added `PoliticalWorldAPI.Settlements.GetSeparatistSentiment(City)`.
- Added capability `settlement.politics.metrics`.

# Political World 1.11.0-dev1

First development build of the 1.11 cycle.

## Monarchy rank progression

Monarchies can now change their political title as they grow:

- 1 small city (< 90 population): Barony
- 1 developed city: County
- 2–3 cities: Duchy
- 4–8 cities: Kingdom
- 9+ cities: Empire

Constitutional monarchies use the same lower ranks, then become Constitutional Kingdoms / Constitutional Empires.

Existing stronger race-specific naming templates (for example Orc Khanates, Dwarf Grand Holds and Elf High Kingdoms) are intentionally preserved for now. Culture-specific rank ladders can be expanded in later 1.11 builds.

Suggested by @Asriel.

## API

PoliticalWorldAPI 1.19:
- `Countries.GetMonarchyRank(Kingdom)`
- `CountryNameTemplateDefinition.RankIds`
- capability: `country-names.monarchy-ranks`

This lets addons register country-name templates for a specific monarchy rank without patching Core.

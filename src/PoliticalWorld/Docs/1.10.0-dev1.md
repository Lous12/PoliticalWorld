# Political World 1.10.0-dev1

Development build for the 1.10 political/ecosystem update.

## Implemented in dev1

- Dynamic political country display names without overwriting vanilla/base names.
- English + Russian localization for the new country-name templates and ideology currents.
- Race political profiles with neutral fallback for unknown/modded races.
- Built-in human/orc/dwarf/elf/Crablin profile presets.
- New ideology currents: Khanism, Agrarianism, Theocratic Traditionalism,
  Technocratic Democracy, Sylvan Concord, Stratocracy, Iron Order,
  Burgundian System, and Forge Syndicalism.
- Rare/secret ideology metadata (`Family`, `Rarity`, `Radicalism`, `IsSecret`).
- Country-name and race-profile registration API for addons.
- Optional cross-mod provider registry (`PoliticalWorldAPI.Interop`).
- Typed election result payloads (winner party/ideology/support/next election).
- Warfare read/start API, including `TryDeclareWar` and `ForceWar`.
- Vanilla player force-war actions bypass Political World's diplomacy interception.
- War started/ended API events with attacker/target/source context.
- API capabilities bumped to 1.15 while retaining 1.14 compatibility flags.

## Important dev-build notes

Dynamic country names are currently a Political World display layer. The original
WorldBox kingdom name is intentionally preserved so player renames and saves stay
safe. Native map labels may therefore continue to show the vanilla base name.

Race tendencies are weights, never hard locks. Unknown races use a neutral profile.
The Burgundian System is intentionally a very rare secret current and should require
an already radicalized fascist regime plus severe political crisis.

## Runtime test checklist

1. Use the vanilla force-war god power and confirm war begins immediately instead of
   becoming a Political World diplomatic crisis/concession.
2. Change ideology/current/government and confirm Political World display names refresh.
3. Run 300-500 year peaceful and war-heavy simulations and compare ideology spread.
4. Confirm Crablins lean right more often without becoming deterministically fascist.
5. Confirm Burgundian System remains genuinely rare.
6. Check Player.log for exceptions during world load, elections, government changes,
   and war starts/peace.

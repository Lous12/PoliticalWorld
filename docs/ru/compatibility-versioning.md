# Совместимость и версионирование API

Версия Political World и версия Public API существуют отдельно.

- Core mod: **1.11.0**
- Public API: **1.19.0**
- Целевая версия игры: WorldBox PC **0.51.2 / build 719**

Аддон должен проверять минимальную версию API, которая ему реально нужна.

Например, если используются только возможности уровня API 1.6:

```csharp
if (!PoliticalWorldAPI.IsCompatible(1, 6)) return;
```

Не надо требовать 1.19 просто потому, что это текущая версия, если аддон не использует новые возможности.

## Правило API 1.x

- **Major** — несовместимые изменения публичного API.
- **Minor** — совместимые новые возможности и публичные методы.
- **Patch** — исправления без намеренной поломки документированного контракта.

Для необязательных возможностей используйте capability check.

Внутренние модули Political World не являются частью контракта совместимости аддонов.

`targetGameBuild` относится к совместимости с WorldBox и не заменяет проверку версии Political World API.

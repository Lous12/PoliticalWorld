# Что можно создавать с помощью Political World?

Political World одновременно является политическим модом и развивающимся фреймворком аддонов.

Главное различие:

> **В Political World есть политика. PoliticalWorldAPI не должен ограничивать фантазию автора только политикой.**

## Что особенно хорошо работает уже сейчас

API 1.9 уже хорошо поддерживает:

- идеологии и течения;
- пользовательские формы правления;
- политические партии и правящую партию;
- политическое состояние государства;
- Event Bus;
- зарегистрированные Actions;
- Rare Events, включая ручной запуск для creator tools;
- Conditions и готовые Effects;
- приватные данные и теги аддона;
- необязательную локализацию с English/readable fallback;
- diagnostics и capability checks.

Поэтому уже сейчас удобно делать:

- ideology packs;
- government packs;
- political event packs;
- расширения партий и выборов;
- Fantasy Politics;
- события династий и правителей;
- scenario/director tools;
- альтернативно-историческую политику;
- creator/debug utilities.

## К чему развивается фреймворк

Универсальное направление должно позволить создавать системы за пределами одной политики, даже если основной Political World сам их не реализует.

Например:

- религии и культы;
- магию и сверхъестественные системы;
- экономику и торговлю;
- болезни и эпидемии;
- технологии;
- профессии;
- RPG/character mechanics;
- династии;
- городские системы;
- собственные мировые события;
- образование и социальные системы;
- creator tools;
- интеграции нескольких независимых аддонов.

Это **цели фреймворка и идеи для аддонов**, а не заявление, что сам Political World уже добавляет все эти механики.

## Начинайте с малого

Полезный аддон может состоять всего из:

- одного события;
- одной идеологии;
- одной формы правления;
- одного Action;
- одного своего значения в данных государства;
- одного listener на событие другого аддона;
- одного маленького инструмента.

Маленькие проекты проще понимать, тестировать и развивать.

## Стройте из универсальных кирпичиков

Направление фреймворка:

```text
Addon
  ↓
Register content
  ↓
Store addon-owned data
  ↓
React to events
  ↓
Check Conditions
  ↓
Apply Effects / Actions
  ↓
Publish events for other addons
```

Чем реже автору приходится трогать внутренности Political World, тем здоровее экосистема.

## Экосистема нескольких аддонов

Не обязательно делать один гигантский overhaul.

Можно иметь несколько небольших модов:

```text
Religion addon ─┐
Magic addon ────┼─→ общие events / capabilities
Economy addon ──┤
Politics addon ─┘
```

Каждый проект остаётся понятным и независимым.

## Scenario Tools

Scenario Tools — наш first-party аддон и одновременно реальный тест Public API.

Он специально должен жить по тем же правилам, что и сторонний мод. Если Scenario Tools не может выразить функцию через Public API, правильное решение — улучшить API.

## Полностью самостоятельные моды WorldBox

Зависеть от Political World всё равно не обязательно.

В репозитории остаются standalone NeoModLoader starter и NML UI cookbook для совершенно самостоятельных модов.

Political World не заменяет NeoModLoader. Он добавляет более высокий уровень инструментов и примеров поверх него.

## С чего начать?

Если хотите зависимый от Political World аддон:

1. Скопируйте `templates/PoliticalWorld-Addon-Template`.
2. Прочитайте [Быстрый старт](GETTING_STARTED.md).
3. Прочитайте [Видение фреймворка](FRAMEWORK_VISION.md).
4. Сделайте одну заметную функцию.
5. Протестируйте её.
6. Если API чего-то не умеет — запросите capability, а не обходите внутренности.

Для полностью самостоятельного мода используйте `templates/WorldBox-NeoMod-Starter`.

# Что можно сделать с помощью Political World?

Political World — это не только сам мод про политику. У него есть Public API, через который другие разработчики могут добавлять свои системы и использовать уже готовую инфраструктуру проекта.

И мы специально хотим, чтобы эта инфраструктура со временем была полезна **не только для политических аддонов**.

## Что удобно делать уже сейчас

API 1.9 уже хорошо подходит для проектов, связанных с политикой:

- новые идеологии и течения;
- свои формы правления;
- политические партии;
- события для государств и правителей;
- наборы Actions и Rare Events;
- расширения выборов и партий;
- Fantasy Politics;
- альтернативно-исторические наборы;
- редакторы и инструменты вроде Scenario Tools.

Кроме этого уже доступны более общие вещи:

- данные и теги аддона;
- Event Bus;
- Conditions и Effects;
- необязательная локализация;
- диагностика;
- проверка возможностей API.

То есть даже сейчас API уже умеет больше, чем просто «добавить новую идеологию».

## Что хотим сделать возможным дальше

Мы хотим, чтобы автор мог использовать PoliticalWorldAPI и для совсем других идей:

- религий и культов;
- магии;
- экономики и торговли;
- болезней и эпидемий;
- технологий;
- профессий;
- механик персонажей;
- династий;
- городских систем;
- мировых событий;
- образования;
- инструментов для других моддеров;
- связок из нескольких независимых аддонов.

Важно: **это не список готовых функций Political World 1.9**. Это примеры того, ради чего мы делаем API более универсальным.

## Не обязательно начинать с огромного мода

Первый проект может быть совсем маленьким:

- одно событие;
- одна идеология;
- одна форма правления;
- один Action;
- одно своё значение в данных государства;
- реакция на событие другого аддона;
- небольшой инструмент для игрока или разработчика.

Такой проект легче закончить, протестировать и понять. А потом уже можно наращивать его по частям.

## Из чего строится аддон

В идеале схема должна быть простой:

```text
Аддон
  ↓
регистрирует свой контент
  ↓
хранит свои данные
  ↓
слушает события
  ↓
проверяет условия
  ↓
применяет эффекты или действия
  ↓
при необходимости сообщает о своих событиях другим аддонам
```

Чем больше этого можно сделать через Public API, тем меньше проект зависит от внутреннего устройства Political World и тем легче переживает обновления.

## Несколько небольших аддонов вместо одного огромного

Нам нравится идея, что экосистема может складываться из независимых проектов.

Например:

```text
Мод на религии ─┐
Мод на магию ───┼─→ общие события и возможности
Мод на экономику┤
Политический мод┘
```

Каждый автор делает свою часть, а аддоны при желании реагируют друг на друга.

## Зачем здесь Scenario Tools

Scenario Tools — наш собственный аддон и одновременно испытательный полигон для Public API.

Мы специально не даём ему особого доступа к внутренним классам Political World. Если нужную функцию нельзя сделать через Public API, значит, у нас появился хороший кандидат на расширение API.

Именно поэтому Scenario Tools полезен не только игрокам: он показывает реальные слабые места платформы.

## А если Political World мне вообще не нужен?

Нормально.

В репозитории остаётся отдельный шаблон для обычного NeoModLoader-мода и материалы по NML. Можно использовать их и делать полностью самостоятельный проект без зависимости от Political World.

Мы не пытаемся заменить NeoModLoader. PoliticalWorldAPI — это более высокий уровень инструментов, который можно использовать там, где он действительно удобен.

## С чего начать

Если хочешь сделать аддон, который зависит от Political World:

1. Скопируй `templates/PoliticalWorld-Addon-Template`.
2. Пройди [быстрый старт](GETTING_STARTED.md).
3. Посмотри [куда мы развиваем API](FRAMEWORK_VISION.md).
4. Сделай одну маленькую, но видимую функцию.
5. Проверь её в игре.
6. Если Public API чего-то не умеет — лучше предложить новую возможность, чем завязываться на внутренние классы.

Для полностью самостоятельного мода используй `templates/WorldBox-NeoMod-Starter`.

# Документация Political World для разработчиков

**ID основного мода:** `Lous12.PoliticalWorld`  
**Public API:** `Lous12.PoliticalWorld.PoliticalWorldAPI`  
**Текущая протестированная версия API:** `1.9.0`  
**Целевая версия WorldBox на ПК:** `0.51.2 / build 719`

Political World — это одновременно сам политический мод и платформа, на которой можно делать аддоны.

Изначально API создавался вокруг политики просто потому, что именно эти системы уже были в моде. Теперь мы постепенно выносим в него более общие инструменты: данные, теги, события, условия, эффекты, действия, локализацию и безопасный доступ к объектам WorldBox.

Поэтому **аддон не обязан быть политическим**.

## Главное правило

Для связи с Political World используй `PoliticalWorldAPI`.

`Main`, `ScenarioBridge` и другие внутренние классы не являются частью публичного контракта. Они могут меняться вместе с устройством самого мода.

Это правило действует и для наших собственных аддонов. Если Scenario Tools или другой first-party проект не может сделать что-то через Public API, мы не даём ему секретный обходной путь — мы расширяем API.

## Производительность

Старайся реагировать на события, а не постоянно сканировать весь мир.

Если задачу можно решить через Event Bus, Action, Condition, Rare Event или сохранённое состояние аддона, это почти всегда лучше собственного `Update()`, который каждый кадр перебирает государства, города или жителей.

Так и сам Political World устроен внутри: больше событий и редких проверок, меньше постоянной тяжёлой симуляции.

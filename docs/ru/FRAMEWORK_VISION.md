# Куда мы развиваем PoliticalWorldAPI

> **Political World не должен решать за автора, какой мод ему можно делать.**

Political World начинался как политический мод, поэтому первые версии API закономерно были почти целиком про идеологии, партии, формы правления и события.

Долгосрочная цель шире: сделать поверх WorldBox + NeoModLoader удобный набор безопасных инструментов для аддонов.

Сам Political World при этом не превращается в «мод на всё». Политика остаётся его собственной игровой системой.

## Что остаётся

- Проект по-прежнему называется **Political World**.
- Публичная точка входа остаётся `Lous12.PoliticalWorld.PoliticalWorldAPI`.
- Аддоны ветки 1.x стараемся не ломать без причины.
- Политика остаётся полноценным модулем.
- Производительность важнее симуляции всего на каждом кадре.
- Наши аддоны должны жить по тем же публичным правилам, что и аддоны сообщества.

## Общее направление

API не должен исходить из того, что каждый новый проект — обязательно политический.

Важнее универсальные инструменты:

- регистрация аддонов;
- capability discovery;
- локализация и fallback;
- данные и теги;
- Event Bus;
- Actions / Conditions / Effects;
- диагностика;
- безопасный доступ к объектам мира;
- UI integration;
- контент, принадлежащий самому аддону.

## Аддоны должны разговаривать друг с другом

Независимые аддоны должны иметь возможность публиковать namespaced events и реагировать на них без жёстких зависимостей.

## Локализация должна ломаться мягко

Отсутствие перевода не должно делать аддон нерабочим. Нормальная цепочка fallback:

1. текущий язык;
2. зарегистрированный текст по умолчанию;
3. английский;
4. DisplayName / Description;
5. читаемый ID.

## Что уже умеет API 1.19

API 1.19 уже даёт широкую базу: регистрацию аддонов, локализацию, data/tags, события, actions, conditions/effects, диагностику, работу с идеологиями/правительствами/партиями, доступ к государствам, warfare helpers, UI integration, lifecycle helpers и другое.

## Куда двигаться дальше

После 1.19 направление остаётся тем же: развивать переиспользуемые возможности API, не превращая core Political World в мод, который пытается симулировать вообще всё.

Если community или first-party addon не может безопасно сделать что-то через public API, это полезный сигнал, что API не хватает capability.

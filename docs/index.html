Political World

A politics mod for WorldBox and a growing addon framework built around PoliticalWorldAPI.

Open on Steam Open GitHub Discussions

One project, two directions

🎮 For players

  • Ideologies and currents
  • Political parties and leaders
  • Governments and elections
  • Crises, coups and revolutions
  • International blocs and summits
  • War preparation and Political Map

🧩 For creators

  • Public API 1.9
  • Addon registration and validation
  • Localization fallback
  • Data, tags and diagnostics
  • Event Bus, Actions, Rare Events
  • Conditions, Effects and political registries

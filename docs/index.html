Development direction

The mod is not abandoned — the foundation is the priority

For a while, large gameplay updates may be less frequent because the focus is on expanding the Public API. The goal is to let other creators build systems and addons without waiting for every idea to be implemented in the core mod.

Roadmap

From political API to general framework

Current stable base

API 1.9

Creator conveniences, localization fallback, addon data, Conditions / Effects, diagnostics and performance work.

Next focus

API 1.10 — General Framework

Generic data and tags for more world objects, safer Actor / City access, custom events, extensible Conditions / Effects, generic content and better cross-addon integration.

Later

UI & ecosystem hooks

Inspector sections, context actions, creator-tool integration, lifecycle helpers and more ways for addons to work together.

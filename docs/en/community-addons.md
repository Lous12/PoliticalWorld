# Community Addons

Political World is designed to be extended by other modders.

This page is the curated catalog of community addons that have been checked for compatibility with a supported Political World version.

## What “verified” means

A verified entry means the Political World maintainer has personally checked the submitted addon on a supported setup and confirmed that it launches and performs its advertised core function.

It is **not** a permanent compatibility promise, security certification, or guarantee that the addon is bug-free. WorldBox, NeoModLoader and Political World updates can change compatibility.

Where practical, addons should use only the public `PoliticalWorldAPI` instead of Political World internals.

## How to submit an addon

Open an Issue or Pull Request in the Political World repository and provide:

- addon name;
- author;
- short description;
- download page;
- source repository, if public;
- required Political World version;
- required PoliticalWorldAPI version;
- other dependencies;
- whether the addon uses only the public PoliticalWorldAPI;
- a short list of features to test.

Small addons are welcome. A one-ideology addon, one-event experiment or learning project can be listed too.

## Review process

Before an addon is added to the verified catalog:

1. its links and stated dependencies are checked;
2. it is installed on a supported Political World setup;
3. the game is launched and logs are checked for obvious addon-related errors;
4. its advertised core feature is tested;
5. its Political World/API requirements are recorded;
6. only then is it added to this page.

If an addon later becomes incompatible, its status can be changed until the author updates it.

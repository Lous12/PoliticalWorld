# Community Addons

Political World is open for community addons, forks and contributions built on top of its Public API.

This is the source Markdown version of the catalog. The friendlier website version is here:  
**https://lous12.github.io/PoliticalWorld/en/community-addons.html**

## Verified addons

**There are no verified community addons listed yet.**

The first projects will appear here after compatibility testing on a supported Political World setup.

## What “verified” means

The addon was launched on a supported Political World setup and its main advertised feature was manually checked.

This is not a security certificate, a permanent compatibility guarantee or a promise that the addon contains no bugs.

Whenever possible, addons should use the public `PoliticalWorldAPI` instead of internal mod classes.

## How to submit your addon

The main submission route is **GitHub Discussions → Addon Testing**:

https://github.com/Lous12/PoliticalWorld/discussions/categories/addon-testing

Please provide:

- addon name;
- author;
- short description;
- download link;
- source link if available;
- Political World version tested;
- PoliticalWorldAPI version tested (current public version: **1.19.0**);
- minimum PoliticalWorldAPI version required by the addon;
- other dependencies;
- whether the addon uses only the Public API;
- the main feature(s) that should be tested;
- whether save/load needs to be part of the test.

Small projects are welcome too.

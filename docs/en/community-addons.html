Verified means tested

The addon launched on a supported setup and its main advertised feature was manually checked.

🧩

Public API first

Using PoliticalWorldAPI instead of internal Main classes makes addons much easier to maintain.

🌿

Forks are welcome

A fork is unofficial unless clearly adopted into the main project, but experiments and alternate directions are welcome.

Submission

What to include

1

Addon name, author, short description and download/source links.

2

The Political World version you tested with and the minimum PoliticalWorldAPI version your addon actually requires.

3

Other dependencies and whether you use only the public PoliticalWorldAPI.

4

A short checklist of what should be tested in-game.

Current repository baseline:

Political World 1.11.0 • PoliticalWorldAPI 1.19.0 • WorldBox 0.51.2 build 719 • NeoModLoader 1.2.0.1. Your addon may require an older API minimum if it only uses older public capabilities.

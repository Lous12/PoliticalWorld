Verification

What we actually check

🔗

Dependencies

Links, required Political World / API versions and other declared dependencies are checked.

▶️

Launch

The addon is installed on a supported setup, the game is launched and the log is checked for obvious addon errors.

🎯

Main feature

The main advertised feature is tested before the addon can be listed in the catalog.

Important:

“Verified” is not a security certificate, a permanent compatibility guarantee or a promise that the addon has no bugs. WorldBox, NeoModLoader and Political World updates can change compatibility.

For addon authors

How to submit an addon

1

Open the Addon Testing category in GitHub Discussions.

2

Provide the addon name, author, short description, download link and source link if available.

3

List the required Political World and PoliticalWorldAPI 1.19+ versions and other dependencies.

4

Briefly describe the main feature that should be checked in-game.
